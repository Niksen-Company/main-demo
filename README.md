# Welcome to your organization's demo respository
This code repository (or "repo") is designed to demonstrate the best GitHub has to offer with the least amount of noise.

The repo includes an `index.html` file (so it can render a web page), two GitHub Actions workflows, and a CSS stylesheet dependency.

## To-do List Demo

The main page has been enhanced with a simple to-do list application built with plain HTML, CSS, and JavaScript. Features include:

- Add new tasks via the input box and "Add" button
- Mark tasks as done/undone
- Delete tasks
- Persistence using `localStorage` so your list survives page reloads

To try it out, open `index.html` in a browser (e.g., via a simple local server like `npx serve` or `python -m http.server`).
