# HowToNiksen To-Do List

A simple, mobile-friendly to-do list web application for [howtoniksen.com](https://www.howtoniksen.com).

## Features

- Add, complete, and delete tasks
- Tasks are saved in the browser via `localStorage` (persist across page reloads)
- Mobile-friendly layout — works on iOS and Android browsers
- Styled with [@primer/css](https://primer.style/css/)

## Deployment

The `index.html` file is the entire application. Point your domain's CNAME record to your hosting provider and serve this file.
