# Welcome to your organization's demo repository

This code repository (or "repo") is designed to demonstrate the best GitHub has to offer with the least amount of noise.

The repo includes an `index.html` file (so it can render a web page), two GitHub Actions workflows, and a CSS stylesheet dependency.

## To-Do List

The `index.html` page now includes a fully functional to-do list application. Features:

- **Add tasks** – type a task and click *Add* (or press Enter).
- **Complete tasks** – click on the task text to toggle it done/undone.
- **Delete tasks** – click the *Delete* button next to a task.
- **Persistent storage** – tasks are saved in `localStorage` so they survive page refreshes.
